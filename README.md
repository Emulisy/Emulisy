## Featured Projects

### [Go Cloud Storage](https://github.com/Emulisy/Go-Cloud-Storage)

> A cloud-backed, content-addressable file storage application built with Go.

Implements SHA-256 deduplication, resumable multipart uploads, Redis-backed
upload sessions, integrity verification, JWT authentication, and user-scoped
file management. Deployed to an Azure VM with Docker Compose, Caddy,
automatic HTTPS, and GitHub Actions.

[`Live Demo`](https://emulisygocloud.southeastasia.cloudapp.azure.com)
&nbsp; [`Architecture`](https://github.com/Emulisy/Go-Cloud-Storage/blob/main/architecture.md)

`Go` `MySQL` `Redis` `Cloudflare R2` `Docker` `Caddy` `Azure`

### [Taskly](https://github.com/Emulisy/Taskly)

> A responsive task-management SPA with authentication and synchronized user data.

Supports task CRUD operations, keyword search, calendar filtering,
completion tracking, starring, dark mode, and Supabase-backed persistence.

`JavaScript` `Supabase` `Vite` `HTML` `CSS`

### [Ticket to Ride](https://github.com/Emulisy/Ticket-to-Ride-Game-Java-Swing)

> A modular Java Swing implementation of Ticket to Ride for 2–5 players.

Uses object-oriented design and multiple design patterns to support
different maps and extensible gameplay features.

`Java 17` `Swing` `OOP` `Design Patterns`
